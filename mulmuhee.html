물무희 딜 계산기

룬과 아티팩트 스탯을 입력하면
예상 딜을 자동으로 계산해드립니다

📋 계산기 기능
  • ✓체력/공격력/방어력/공속 룬 스탯 기반 최종 스탯 계산
  • ✓아티팩트 옵션 (체력/공격력/방어력/공속 비례 추가피해) 반영
  • ✓버프 후 스탯 자동 계산 (공격력 버프, 속버프 포함)
  • ✓투지 세트 효과 반영
  • ✓상대 방어력 / 물뎀감 기반 기대 데미지 산출
🚀 사용 방법
1

아래 버튼을 눌러 내 드라이브에 사본 복사

2

C열에 내 룬/아티 스탯 입력

3

기대 데미지 자동 계산 확인

💡

아래 버튼을 클릭하면 구글 스프레드시트 사본이 내 구글 드라이브에 복사됩니다. 원본은 수정되지 않으며, 복사된 파일은 본인만 소유합니다.

📋 내 구글 드라이브에 사본 복사하기 구글 계정 로그인 필요 · 원본 훼손 없음

버튼 클릭 시 구글 로그인 페이지로 이동할 수 있습니다.
로그인 후 "사본 만들기"를 클릭하면 내 드라이브에 저장됩니다.
